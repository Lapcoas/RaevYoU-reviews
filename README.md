# RaevYoU — отзывы

Статичный сайт: `index.html`, `style.css`, `script.js`. Работает на GitHub Pages.

## Почему нужна база

GitHub Pages только отдаёт файлы — сохранять отзывы он не умеет.
Чтобы отзыв, написанный одним человеком, видели все, отзывы хранятся
в бесплатной базе Supabase. Подключение — 4 шага, около 5 минут.

## Подключение

1. Зарегистрируйтесь на https://supabase.com и создайте проект (New project, бесплатный тариф).
2. Откройте **SQL Editor** → **New query**, вставьте всё из файла `supabase-setup.sql` и нажмите **Run**.
3. Откройте **Project Settings → API** (или **API Keys**) и скопируйте:
   - **Project URL**
   - публичный ключ: **anon** (или **publishable**)
4. В начале файла `script.js` вставьте их:

   ```js
   const CONFIG = {
     SUPABASE_URL: 'https://xxxx.supabase.co',
     SUPABASE_ANON_KEY: 'ваш_публичный_ключ',
   };
   ```

Публичный ключ можно хранить в коде — таблица закрыта, сайт умеет только
читать список, добавлять отзыв и менять **свой** отзыв (по секретному коду из браузера автора).
Секретные ключи (`service_role`, `secret`) в код вставлять нельзя.

## Выкладка на GitHub Pages

1. Создайте репозиторий, загрузите `index.html`, `style.css`, `script.js` (README и SQL можно не загружать).
2. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
3. Через минуту сайт откроется по ссылке `https://ваш-ник.github.io/название-репозитория/`.

## Модерация

Удалить отзыв: Supabase → **Table Editor → reviews** → выберите строку → Delete.
Автор после этого снова сможет написать новый отзыв.

## Как работает «один отзыв»

После публикации браузер запоминает секретный код отзыва. Кнопка «Написать свой отзыв»
превращается в «Изменить мой отзыв» (карандаш также есть на самой карточке).
Ограничение держится на браузере: человек, который откроет сайт в другом браузере
или очистит данные сайта, сможет написать ещё один. Полная защита возможна только
со входом (например, через Telegram), это отдельная доработка.

## Демо-режим

Пока `CONFIG` пуст, сайт работает без базы: отзывы хранятся только в вашем браузере.
Так можно посмотреть и проверить внешний вид до подключения Supabase.
